## The entry

One sentence a house cat would say in its own defence, five seconds after
sweeping a glass off the table — no apology, no confession, just the cat's
own logic:

> At 6:47 that glass parked itself in my sunbeam like it paid rent, so I evicted it.

## How it works

`main.py` writes that single sentence (82 characters, one sentence) to
`/output/entry.txt`. The readable source is `line_src.py`; `main.py` is the
packed form produced by `makefun compress`.

Run it locally:

```sh
python3 main.py
cat /output/entry.txt
```
